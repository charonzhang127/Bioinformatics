## 第三部分：序列比对、基因组组装与注释 (51-75题)

这部分题目进入生物信息学的核心领域，概念性问题和伪代码编程题相结合。

**题目**

1. 什么是全局比对（Global Alignment）？它适用于哪种情况？从两条序列全场首尾进行完整比对，整条序列的最优匹配，是用来衡量两条序列整体的相似性，满足整体相似性最大化
2. 什么是局部比对（Local Alignment）？它适用于哪种情况？只找相似度最高的局部片段，找到相似性的片段和其相应的匹配方式
3. Needleman-Wunsch算法用于解决哪种比对问题？全局对比
4. Smith-Waterman算法用于解决哪种比对问题？局部对比
5. 在序列比对中，什么是“Gap Penalty”？为什么需要它？-> 是序列比对出现空位（代表进化出现插入或缺失突变）时，扣除的比对分值，分为开空位罚分和延申罚分。重要性：防止为了匹配而随意插入序列
6. 解释BLAST程序的用途。BLAST是全局比对还是局部比对？->用于局部匹配的软件
7. 什么是E-value（期望值）？在BLAST结果中，E-value越小意味着什么？随机匹配上这段相似序列的条数。E-value越小说明两条序列同源的概率越高
8. 什么是“De novo”基因组组装？从头组装不依靠任何参考基因组
9. 什么是基于参考基因组的组装（Reference-based Assembly）？已有该物种标准参考基因组拿测序段片段挨个上去拼接
10. 解释“Contig”和“Scaffold”在基因组组装中的区别。Contig（重叠群）：reads互相重叠拼出来的连续DNA片段，没有缺口。| Scaffold（支架序列）：把多个远近已知的Contig按顺序串在一起，Contig中间未知的空白用N填充。
11. 什么是覆盖度（Coverage）？在测序和组装中它为什么重要？就是测序深度，基因组总长度 ÷ 所有测序 reads 总长度 = 平均深度。重要的原因：要不同的测序取到合适的深度。
12. 什么是N50？如何计算一个基因组组装项目的N50？-> 把所有 contig 或 scaffold 从长到短排序，从最长开始挨个累加长度，加到总长度刚好占到全部序列总长 50% 时，最后那一段的长度 = N50。
13. 基因组注释（Genome Annotation）包含哪两个主要方面？-> 结构注释和功能注释：结构注释是在组装好的 DNA 序列上，标出基因在哪、非编码区在哪；功能注释是给找出来的基因定功能，这个基因编码什么蛋白、参与什么通路、同源基因、生物学功能。
14. 什么是开放阅读框（Open Reading Frame, ORF）？-> ORF 就是一段能连续翻译成蛋白的 DNA 片段,必备 3 个条件：开头：起始密码子 ATG; 中间：连续成串 3 碱基一组，没有提前碰到终止密码（TAA/TAG/TGA）; 末尾：最后出现终止密码子
15. 基因预测（Gene Prediction）的两种主要策略是什么？-> (1)从头预测（ab initio 预测）只靠DNA 序列本身特征找基因：找 ATG、终止密码、外显子剪切位点、密码子偏好，软件：Augustus、Genscan。(2) 同源 / 证据驱动预测（基于证据）拿已知 mRNA、EST、近缘物种蛋白、转录组 reads去比对基因组，按着比对痕迹框出外显子、基因位置。
16. 什么是同源基因（Homologous Genes）？请解释直系同源（Orthologs）和旁系同源（Paralogs）的区别。直系同源：物种分化产生（种间），同一个祖先物种分化成两个新物种，祖先基因跟着分到两个物种里。旁系同源：同物种，物种内部基因发生复制，一条变成两条，留在同一个基因组
17. BWA和Bowtie2是常用的什么工具？它们主要用于什么任务？-> 高通量短读段序列比对工具,用于把二代测序得到的大量短 reads 定位、比对到参考基因组序列上，输出 SAM/BAM 比对文件，这是重测序、ChIP-seq、基因组变异检测、基因组组装纠错的第一步。[BWA]: DNA测序（全基因组重测序 WGS、外显子测序 WES）、SNP/Indel 变异挖掘（搭配 GATK）--变异位点筛查。[Bowtie2]:高速比对、ChIP-seq、甲基化测序 BS-seq、无突变分析需求的富集测序（速度更快、内存占用更低，支持空位比对、局部比对）
18. SAM/BAM文件的主要用途是什么？-> 找变异（SNP / Indel）/  可视化查看比对情况 / 计算表达量（RNA-seq）/ 峰检测（ChIP-seq / ATAC-seq）
19. 什么是变异检测（Variant Calling）？VCF文件是用来存储什么信息的？ -> 变异检测：把测序数据和参考基因组对比，找出不一样的地方。VCF：存所有突变位点的文件

21. 解释重叠-布局-共有（Overlap-Layout-Consensus, OLC）组装策略的基本思想。-> Overlap（找重叠）: 两两比对所有 reads，算出哪两条序列末端碱基能接上、重叠区多长，把所有配对重叠关系找出来。 | Layout（排布骨架）: 根据重叠信息，把一条条 reads 串成连续的长串，确定每条片段的先后顺序、相对位置，搭出 contig 大体排列。 | Consensus（生成一致序列）: 同一个基因组位置有多条 reads 覆盖，多数碱基是什么就定什么，纠错，拼接出最终连续的 consensus 序列（Contig）。
22. 解释德布鲁因图（De Bruijn Graph, DBG）组装策略的基本思想。-> 把 reads 切成固定长度 k-mer，用 k-mer 建图拼接。步骤：(1)拆分 k-mer，把每条测序 read 切成连续、长度 = k 的小片段（k-mer）[例：read=ATGTC，k=3 → ATG、TGT、GTC] (2)构建图：k-1 碱基当节点，多出 1 个碱基当边。节点：k-mer 去掉最后 1 个碱基（k-1mer）、去掉最前 1 个碱基（k-1mer），前后 k-mer 差一个碱基就连一条边，连成通路

24. 什么是基因本体论（Gene Ontology, GO）？它如何帮助我们理解基因功能？-> 一套全球统一的基因功能标准化注释词汇库，把所有基因的功能分成三大类：BP：Biological Process
